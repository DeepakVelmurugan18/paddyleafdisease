# 🌾 Paddy Leaf Disease Detection using Deep Learning

An AI-powered Paddy Leaf Disease Detection system built using **TensorFlow/Keras** and **EfficientNetB0** for identifying diseases in paddy leaves through image classification.

This project helps farmers and researchers detect crop diseases early and improve agricultural productivity using deep learning and computer vision.

---

## 🚀 Features

- 🌱 Detects multiple paddy leaf diseases
- 🧠 Deep Learning model using EfficientNetB0
- 🖼️ Image preprocessing and augmentation
- ⚡ Real-time disease prediction from uploaded images
- 📊 High accuracy classification model
- 🔍 Transfer Learning implementation
- 📈 Model training and evaluation visualization

---

## 🦠 Diseases Detected

- Bacterial Leaf Blight (BLB)
- Brown Spot
- Leaf Blast
